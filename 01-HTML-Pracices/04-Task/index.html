About HTML

HTML is the standard markup language for creating web pages. It consists of a series of elements that "wrap" content to make it appear a certain way.

Common HTML Tags

  • <h1> to <h6> for headings
  • <p> for paragraphs
  • <a> for hyperlinks
  • <img> for images
